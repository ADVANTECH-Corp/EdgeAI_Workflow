# Overview
This folder contains the process and instructions for AI development on the AOM-DK2721 (Qualcomm QCS6490).


![eas_ai_workflow](/assets/qualcomm/eas_startkit_aom-dk2721.png)


## Edge AI SDK - Windows Prerequisite

Use the workflow need to base on Edge AI SDK.

Install Edge AI SDK(v3.5.0) : [Download](https://docs.edge-ai-sdk.advantech.com/docs/Hardware/AI_System/Qualcomm/QCS6490/AOM-DK2721-Windows#Win11_snpe239)
> This prerequisite applies only to the Windows workflows.  
> The Yocto/Linux workflows do not require Edge AI SDK installation.
